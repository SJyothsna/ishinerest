Smart Linked Dropdown Logic

Wherever a foreign-key ID is needed (chapterId, subjectId etc.), the form shows a human-readable name loaded from the API. The ID is sent to the backend silently.

→
Backend ID
sent in POST body

This cascade is used in: Questions · Notes (create & list filter). Subjects, Chapters, Classes use partial cascades for their list filters.

UI / Design Features

  • Sidebar NavSticky left column, 220px wide, active state with blue left-bar indicator, grouped under "Controllers" heading
  • Sub-tabsEvery controller has Create and List sub-tabs (some have more e.g. Assign, Detail)
  • Filter BarQuery-param inputs above every list view; Fetch button triggers the request on demand
  • Resource TableCompact thead, ID badges in monospace code style, text truncation with full tooltip on hover
  • Inline AlertsSuccess (green) / error (red) / info (blue) alerts with × dismiss button, auto-clear on success
  • SpinnersCSS-only spinner on all async operations — no library dependency
  • Form Grid2-col and 3-col CSS grid layouts, collapses to 1-col on mobile
  • Zero hard-coded IDsAll reference data loaded live from backend; dropdowns disabled until parent is selected
  • Role guardPage redirects to / if userRole is not ADMIN or TEACHER
